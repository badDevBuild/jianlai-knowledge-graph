# 《剑来》领域知识速查

> 从 CLAUDE.md 迁出的领域知识参考，供需要小说背景时查阅。

## 主要人物

- **陈平安**: 主角，泥瓶巷少年 → 剑气长城隐官 → 止境武夫+飞升境剑修
- **齐静春**: 文圣，大骊书院山主
- **崔瀺**: 文海周密大真人，陈平安的师父之一
- **宁姚**: 女武神，陈平安的爱慕对象
- **崔东山**: 崔瀺阳神分身，陈平安的首席弟子
- **裴钱**: 陈平安的养女，武道天才
- **老秀才**: 儒家文圣一脉掌教

## 主要地点

- **骊珠洞天**: 小说开篇的小镇所在世界
- **剑气长城**: 浩然天下与蛮荒世界的边界
- **落魄山**: 陈平安的宗门
- **大骊王朝**: 宝瓶洲最强王朝
- **白玉京**: 青冥天下道家祖庭

## 核心概念

- **飞剑**: 剑修的本命法宝 (如"十五"、"初一")
- **小天地**: 修士的个人洞府空间
- **谪仙人**: 从天而降的仙人
- **山上/山下**: 修士世界 vs 凡人世界
- **隐官**: 剑气长城的秘密领袖职位

## 修真境界体系

**修士境界** (14个):
泥瓶境 → 铜皮境 → 草根境 → 柳筋境 → 骨架境 → 五境 (洞府、观海、龙门、金丹、元婴) → 玉璞境 → 飞升境 (下五境/上五境) → 十四境

**武夫境界** (11个):
泥腿境 → 草根境 → 柳筋境 → 骨架境 → 木胎境 → 五境 (洞府等) → 远游境 → 山巅境 → 止境 → 十境 → 十一境

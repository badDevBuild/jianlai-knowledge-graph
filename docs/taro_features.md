## 人物卡片分享 (已完成)

**文件**: `taro-app/src/utils/cardGenerator.ts`

**设计稿**: `pencil-new.pen` (Pencil 设计工具)

**设计风格**: 水墨画模板背景 + 金色点缀 + 暗色文字衬底

**卡片元素** (750x1100 Canvas 2D):
1. 水墨模板背景 (`card-template.jpg`) + 渐变降级
2. 四角金色 L 形角标装饰
3. 金色边框头像 (300x380)
4. 名字 (白色 + 双层阴影，无遮罩方案)
5. 金色分割线
6. 境界徽章 (半透明黑底 + 金色文字)
7. 势力标签 (半透明黑底 + 灰色文字)
8. 语录 (半透明黑底 + 灰色文字，自动换行)
9. 标签胶囊 (淡金底 + 金色文字)
10. 底部: 小程序二维码 (`qrcode.png`) + "长按识别小程序码" + "剑来光阴"

**静态资源**: `taro-app/src/assets/images/`
- `card-template.jpg` — 水墨画背景 (750x1100, 159K)
- `qrcode.png` — 小程序码 (430x430, 97K)

## 金句卡片分享 (已完成)

**文件**: `taro-app/src/utils/quoteCardGenerator.ts`

**设计风格**: 淡色水墨风（与首页金句模块一致）

**卡片元素** (750x1000 Canvas 2D):
1. 背景图 (复用首页竹/山水图) + 暖色宣纸遮罩 (rgba(247,246,242,0.88))
2. 居中大引号装饰 (淡蓝色)
3. 居中金句文字 (深墨 #1a1a1a, 38px 宋体, 自动换行, 垂直居中)
4. 蓝色短横线 + 作者名 (居中, #3b82f6)
5. 底部: 小程序二维码 + "长按识别小程序码" + "剑来光阴"

**入口**: 首页金句模块左下角"分享此金句"按钮

# 《剑来 · 万象图录》UI 设计交付文档

> **交付对象**: UI 设计师  
> **产品**: 微信小程序  
> **期待产出**: 页面交互原型 (Figma/Sketch)  
> **日期**: 2025-12-29

---

## 一、产品简介

**一句话描述**: 《剑来》小说的知识图谱伴读工具，帮用户查人物、理关系、问问题。

**设计调性**: 中国风水墨 × 现代极简，沉浸感 > 功能感

---

## 二、页面清单 & 优先级

| 页面 | 入口 | 优先级 | 说明 |
|-----|------|-------|------|
| 首页 | TabBar | P0 | 每日金句 + 搜索入口 + 热门角色 |
| 人物列表 | 图鉴Tab | P0 | 卡片流，可筛选势力/境界 |
| 人物详情 | 点击卡片 | P0 | 核心页面，信息最密集 |
| **法宝列表** | 图鉴Tab → 法宝 | P1 | 神兵利器图鉴，按类型筛选 |
| **法宝详情** | 点击法宝卡片 | P1 | 描述+持有者变迁时间线 |
| **势力列表** | 图鉴Tab → 势力 | P1 | 宗门/王朝/组织分类 |
| **势力详情** | 点击势力卡片 | P1 | 成员列表+关联地点 |
| 关系图谱 | 探索Tab | P1 | 力导向图，可缩放拖拽 |
| AI 问答 | AI Tab | P1 | 对话式交互 |
| 金句殿堂 | 首页点击 | P1 | 瀑布流金句卡片 |
| 时间线 | 探索Tab | P2 | 横向滚动时间轴 |
| 个人中心 | 我的Tab | P2 | 收藏/设置 |

## 三、核心用户流程

### 流程 1：查人物 (P0)
```
首页 → 点击搜索框 → 输入"陈平安" → 搜索结果列表 → 点击卡片 → 人物详情页
                                                        ↓
                                                 点击"关系网络"
                                                        ↓
                                                 关系图谱(聚焦该角色)
```

### 流程 2：问问题 (P1)
```
TabBar点击"AI" → AI问答页 → 输入问题 → 等待(打字机动画) → 显示回答 → 可追问
```

### 流程 3：浏览金句 (P1)
```
首页"每日金句"卡片 → 点击"更多" → 金句殿堂列表 → 点击某金句 → 预览分享海报 → 保存/分享
```

### 流程 4：查法宝 (P1)
```
图鉴Tab → 顶部切换"法宝" → 法宝列表页 → 点击卡片 → 法宝详情页 → 查看"持有者变迁"
```

### 流程 5：查势力 (P1)
```
图鉴Tab → 顶部切换"势力" → 势力列表页 → 点击卡片 → 势力详情页 → 点击成员跳转人物详情
```

## 四、页面原型规格

### 4.1 首页 (Home)

```
┌────────────────────────────────────┐
│  剑来 · 万象图录              [设置] │  ← 顶部导航
├────────────────────────────────────┤
│  🔍 搜索人物、法宝、势力...         │  ← 搜索框(假输入框，点击跳转)
├────────────────────────────────────┤
│  ┌────────────────────────────┐   │
│  │                            │   │
│  │   "世间事，人间情，         │   │  ← 每日金句卡片
│  │    皆需一个'忍'字"         │   │     (水墨背景，可滑动换)
│  │           —— 陈平安        │   │
│  │                            │   │
│  └────────────────────────────┘   │
├────────────────────────────────────┤
│  热门人物           [查看全部 >]   │  ← Section 标题
│  ┌──────┐ ┌──────┐ ┌──────┐      │
│  │ 头像 │ │ 头像 │ │ 头像 │      │  ← 横向滚动卡片
│  │陈平安│ │宁 姚│ │齐静春│      │
│  └──────┘ └──────┘ └──────┘      │
├────────────────────────────────────┤
│  首页    图鉴    探索    AI    我的 │  ← 底部TabBar
└────────────────────────────────────┘
```

**交互说明**:
- 每日金句卡片支持左右滑动切换
- 点击金句卡片 → 展开全屏 + 分享按钮
- 搜索框点击 → 跳转独立搜索页

## 六、关键动效说明

| 场景 | 动效 | 时长 |
|-----|------|-----|
| 页面转场 | 右滑返回，左滑进入 | 300ms |
| 卡片点击 | 轻微缩放(0.98)+阴影加深 | 150ms |
| 按钮点击 | 涟漪扩散 (Ripple) | 400ms |
| AI 回答 | 打字机逐字显示 | 30ms/字 |
| 弹窗 | 底部上滑 + 遮罩渐显 | 300ms |
| 金句切换 | 淡入淡出 | 500ms |
